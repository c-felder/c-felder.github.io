# Christopher Felder academic website

A responsive static website designed for GitHub Pages.

## Customize
1. Replace bracketed placeholder text in the HTML files.
2. Replace every `you@university.edu` with your email.
3. Add `headshot.jpg` and follow `assets/README.txt`.
4. Replace `#` links with your real URLs.

## Publish with GitHub Pages
Upload these files to the root of a GitHub repository, then enable GitHub Pages for the repository using the main branch and root folder.

## arXiv
The research page uses arXiv's myarticles widget with author ID `felder_c_1`.
